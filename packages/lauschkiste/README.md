# Lauschkiste core

The core of [Lauschkiste](https://github.com/ladidadida/lauschkiste), an open-source RFID audio player for kids: player, library,
cards, volume, timers, the web API and the web app, and the contract plugins are built on.

This package is a dependency, not something to install on its own. Install
[`lauschkiste`](https://pypi.org/project/lauschkiste/), which brings the `lauschkiste` and
`lauschctl` commands. The Python module is `lauschkiste`; versions of all Lauschkiste packages
match exactly.

Documentation: [guide](https://ladidadida.github.io/lauschkiste/en/) (also in [German](https://ladidadida.github.io/lauschkiste/de/)), [for developers](https://ladidadida.github.io/lauschkiste/en/developers/). MIT license.
