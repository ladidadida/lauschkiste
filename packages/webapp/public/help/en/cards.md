# Cards

A card starts an action, usually an album, audiobook, station or podcast.

## Registering a card

- **Easiest:** play something, tap the card button in the player, place the card.
- **Unknown card:** when a new card is placed, the player shows "Register".
- **Card list:** Settings → Cards → Open the card list → "+"; then place the card and choose an action.

While registering, a card that is already in use doesn't start playing.

## What a card can do

| Action | Effect |
| --- | --- |
| Play music | album, folder or single song |
| Play audiobook | continue where it stopped, or from the beginning |
| Play radio | a station |
| Play podcast | newest unheard or a given episode |
| Audio & volume | louder/quieter, pause, next, previous, … |
| Timers, system | stop timer, read out the IP address, shut down |

## The same card again

What happens when a folder card is placed again while its folder plays (pause/continue, restart, next song, nothing) is set under Settings → Cards. Audiobook cards always continue.

## Reader

The reader is set up once on the box: [Commands on the box](/help/lauschctl?section=reader). Settings → Cards shows which readers run.
