# Welcome to Lauschkiste

Lauschkiste plays music, audiobooks, podcasts and radio as soon as a card is placed on it. The web app is for setting it up and controlling it; day to day the box works without a screen.

## Your first card in three steps

1. **Upload:** Library → Music → Folders (or Audiobooks → Folders) → Upload. One folder per album or audiobook. More in [Library](/help/library).
2. **Play:** tap an album, audiobook, station or podcast in the library.
3. **Put it on a card:** tap the card button in the player and place the card. From now on the card starts exactly that. More in [Cards](/help/cards).

## The parts of the app

| Part | For |
| --- | --- |
| Start | The player: what is playing, controls, sleep timer, search, putting it on a card |
| Library | Continue, music, audiobooks, radio, podcasts; uploading files |
| Settings | Status, playback, cards, library, plugins, system |
| Help | These pages |

Some settings change the box's operating system and need administrator rights. You set them up once on the box with `lauschctl`, see [Commands on the box](/help/lauschctl).
