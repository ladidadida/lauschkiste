# Willkommen bei Lauschkiste

Lauschkiste spielt Musik, Hörbücher, Podcasts und Radio, sobald eine Karte aufgelegt wird. Die Web-App ist zum Einrichten und Bedienen da, die Box selbst kommt im Alltag ohne Bildschirm aus.

## In drei Schritten zur ersten Karte

1. **Inhalte hochladen:** Bibliothek → Musik → Ordner (oder Hörbücher → Ordner) → Hochladen. Je Album bzw. Hörbuch ein eigener Ordner. Mehr unter [Bibliothek](/help/library).
2. **Abspielen:** In der Bibliothek ein Album, Hörbuch, einen Sender oder Podcast antippen.
3. **Auf eine Karte legen:** Im Player auf das Karten-Symbol tippen und die Karte auflegen. Ab jetzt startet die Karte genau das. Mehr unter [Karten](/help/cards).

## Die Bereiche der App

| Bereich | Wofür |
| --- | --- |
| Start | Der Player: was gerade läuft, Bedienung, Einschlaf-Timer, Suche, Karte belegen |
| Bibliothek | Weiterhören, Musik, Hörbücher, Radio, Podcasts; Dateien hochladen |
| Einstellungen | Status, Wiedergabe, Karten, Bibliothek, Plugins, System |
| Hilfe | Diese Seiten |

Manche Einstellungen ändern das Betriebssystem der Box und brauchen Administratorrechte. Die richtest du einmalig auf der Box mit `lauschctl` ein, siehe [Befehle auf der Box](/help/lauschctl).
