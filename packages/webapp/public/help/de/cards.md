# Karten

Eine Karte startet eine Aktion, meist ein Album, Hörbuch, einen Sender oder Podcast.

## Karte anlernen

- **Am einfachsten:** etwas abspielen, im Player auf das Karten-Symbol tippen, Karte auflegen.
- **Unbekannte Karte:** Liegt eine neue Karte auf, zeigt der Player „Anlernen“.
- **Kartenliste:** Einstellungen → Karten → Kartenliste öffnen → „+“; dann die Karte auflegen und eine Aktion wählen.

Solange angelernt wird, spielt eine schon belegte Karte nicht los.

## Was eine Karte kann

| Aktion | Wirkung |
| --- | --- |
| Musik abspielen | Album, Ordner oder einzelner Titel |
| Hörbuch abspielen | fortsetzen, wo es aufgehört hat, oder von vorn |
| Radio abspielen | ein Sender |
| Podcast abspielen | neueste ungehörte oder eine bestimmte Folge |
| Audio & Lautstärke | Lauter/leiser, Pause, Vor, Zurück, … |
| Timer, System | Ausschalt-Timer, IP-Adresse ansagen, Herunterfahren |

## Gleiche Karte noch einmal

Was passiert, wenn eine Ordner-Karte erneut aufgelegt wird, während ihr Ordner läuft (Pause/Weiter, von vorn, nächster Titel, nichts), stellst du unter Einstellungen → Karten ein. Hörbuch-Karten setzen immer fort.

## Lesegerät

Das Lesegerät wird einmalig auf der Box eingerichtet: [Befehle auf der Box](/help/lauschctl?section=reader). Welche Lesegeräte laufen, zeigt Einstellungen → Karten.
