# Security Policy

Lauschkiste is alpha software, only the latest release is supported.

Please report vulnerabilities **privately** with the "Report a vulnerability" form in the Security tab of
the [repository](https://github.com/ladidadida/lauschkiste/security), not in a public issue. Include what you
found, how to reproduce it and the version (Settings → Status in the web app).

Lauschkiste runs on a box in your home network and the web app has no login: do not expose it to the
internet.
