# What you need

You can build a Lauschkiste in an afternoon. Nothing needs soldering for the basic version.

## The parts

| Part | What for | Notes |
| --- | --- | --- |
| A Raspberry Pi | the brain of the box | A Pi 3, Pi 4 or Zero 2 is comfortable. A Pi Zero W works too, but the installation takes about ten minutes longer. |
| A microSD card, 16 GB or more | the box's memory | Music takes space; a bigger card holds more. |
| A power supply for the Pi | | The one that fits your Pi model. |
| An RFID reader | reads the cards | The easy start is a USB reader. Readers that you wire to the Pi are described in [RFID readers](../hardware/readers.md). |
| RFID cards, stickers or key fobs | one per album, book or station | Buy ones that match the reader's frequency (125 kHz or 13.56 MHz). |
| Speakers | | Active speakers with a headphone plug, a USB speaker, or a small amplifier board, see [sound cards](../hardware/sound-cards.md). |

You also need a computer, tablet or phone in the same WiFi to open the web page that controls the box, and a way to
write the SD card (a computer with a card slot or a card reader).

## What you do not need

- No screen or keyboard on the box. Everything is set up from your computer.
- No programming. You type a few commands once, copy and paste is enough.

## Before you start

- Decide on a name for the box, for example `lauschkiste`. It becomes the address of the web page.
- Have your WiFi name and password at hand.
- Put your music in folders on your computer, one folder per album or audiobook.
