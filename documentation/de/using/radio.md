# Radio

Internetradio-Sender haben einen Namen, eine Adresse und optional ein Bild. Jede Karte spielt einen Sender.

## Sender hinzufügen

Öffne in der Bibliothek **Radio** und tippe auf **Sender hinzufügen**:

- **Suchen.** Mit dem Plugin *Radio-Verzeichnisse* (Einstellungen → Plugins) durchsucht der Dialog
  [radio-browser.info](https://www.radio-browser.info), ein offenes Verzeichnis. Tippe einen Namen oder ein Thema wie
  „kinder“ ein; die Sender erscheinen mit Logo, Land und Bitrate. Ohne Suchbegriff siehst du die beliebten Sender deines
  Landes. Ein Tipp fügt einen Sender hinzu. Was du eintippst, geht an radio-browser.info.
- **Per Adresse.** *Per Adresse hinzufügen* nimmt die Adresse des Streams. Es darf auch eine `.m3u`- oder `.pls`-Datei von
  der Webseite des Senders sein; die Box findet den Stream darin.

Das Menü neben dem Knopf importiert und exportiert Senderlisten als `.m3u`-Dateien, das Format der Radio-Apps.

## Auf einer Karte

Spiel den Sender ab und tippe im Player auf das Karten-Symbol, oder wähle beim Registrieren in der Kartenliste *Radio
abspielen*.

## Während er spielt

Der Player zeigt Bild und Name des Senders und das, was der Sender über sich sagt: den aktuellen Titel, soweit er
gesendet wird. Reißt ein Stream ab, verbindet sich die Box von selbst neu.

Die zuletzt gehörten Sender stehen unter Bibliothek → **Weiterhören**. Über das Menü lässt sich ein Eintrag aus dieser
Liste entfernen (der Sender bleibt). In derselben Liste stehen auch Hörbücher und Podcasts.
