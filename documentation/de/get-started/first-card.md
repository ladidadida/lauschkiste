# Deine erste Karte

Diese Seite setzt einen RFID-Leser voraus, der mit der Box funktioniert (siehe [RFID-Leser und Karten](../hardware/readers.md);
ein USB-Leser ist der einfache Start), und etwas zum Abspielen: hochgeladene Musik, einen Radiosender oder einen Podcast,
siehe [Die Box läuft](first-steps.md).

## Auf eine Karte legen

1. Lass das Album, den Sender oder den Podcast spielen und tippe im Player auf das **Karten-Symbol**.
2. Halte eine Karte auf das Lesegerät.
3. Die Karte ist jetzt registriert. Nimm sie weg und leg sie wieder auf: Es startet erneut.

Eine neue Karte, die die Box noch nicht kennt, zeigt im Player **Registrieren**. Alle Karten stehen unter
Einstellungen → Karten.

## Übergeben

Gib die Karte deinem Kind. Das ist die ganze Idee: Karte drauf, Musik läuft.

Weitere Karten funktionieren genauso. Außer Alben kann eine Karte einen Podcast, einen Radiosender oder ein Hörbuch
starten oder Dinge tun wie *lauter*, *Pause* oder *ausschalten*: siehe [Karten](../using/cards.md).
