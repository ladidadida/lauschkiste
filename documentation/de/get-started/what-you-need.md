# Was du brauchst

Eine Lauschkiste baust du an einem Nachmittag. Für die einfache Version musst du nichts löten.

## Die Teile

| Teil | Wofür | Hinweise |
| --- | --- | --- |
| Ein Raspberry Pi | das Gehirn der Box | Ein Pi 3, Pi 4 oder Zero 2 ist angenehm. Ein Pi Zero W geht auch, aber die Installation dauert etwa zehn Minuten länger. |
| Eine microSD-Karte, 16 GB oder mehr | der Speicher der Box | Musik braucht Platz; je größer die Karte, desto mehr passt drauf. |
| Ein Netzteil für den Pi | | Das passende zu deinem Pi-Modell. |
| Ein RFID-Leser | liest die Karten | Am einfachsten ist ein USB-Leser. Leser, die du an den Pi anschließt, stehen unter [RFID-Leser](../hardware/readers.md). |
| RFID-Karten, Aufkleber oder Anhänger | eine pro Album, Buch oder Sender | Kauf solche, die zur Frequenz des Lesers passen (125 kHz oder 13,56 MHz). |
| Lautsprecher | | Aktive Lautsprecher mit Kopfhörerstecker, ein USB-Lautsprecher oder eine kleine Verstärkerplatine, siehe [Soundkarten](../hardware/sound-cards.md). |

Dazu brauchst du einen Computer, ein Tablet oder ein Handy im selben WLAN, um die Webseite zu öffnen, die die Box steuert,
und eine Möglichkeit, die SD-Karte zu beschreiben (ein Computer mit Kartenschacht oder ein Kartenleser).

## Was du nicht brauchst

- Keinen Bildschirm und keine Tastatur an der Box. Alles wird von deinem Computer aus eingerichtet.
- Keine Programmierkenntnisse. Du tippst einmal ein paar Befehle; Kopieren und Einfügen genügt.

## Bevor du anfängst

- Überlege dir einen Namen für die Box, zum Beispiel `lauschkiste`. Er wird zur Adresse der Webseite.
- Halte den Namen und das Passwort deines WLANs bereit.
- Lege deine Musik auf dem Computer in Ordner, ein Ordner pro Album oder Hörbuch.

Weiter: [Installieren](install.md).
