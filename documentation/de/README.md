# Lauschkiste: die Anleitung

Lauschkiste ist eine Musikbox für Kinder. Man legt eine Karte auf, und die Musik, das Hörbuch, der Podcast oder der
Radiosender, der zur Karte gehört, startet. Erwachsene richten alles auf einer Webseite ein; die Kinder brauchen nur die
Karten.

[English](../en/README.md)
